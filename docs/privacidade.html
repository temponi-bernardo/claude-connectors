Política de privacidade

Atualizada em 14 de novembro de 2026.

Esta política vale para os conectores do projeto Claude Connectors, mantido por Bernardo Temponi, hoje o conector Canvas PUC Minas. Ele roda só na nuvem e é usado pelo plugin do marketplace ou como conector personalizado no claude.ai, no Cowork, no app do celular e no Claude Code.

Que dados são acessados

Só os dados da sua própria conta no Canvas, e só quando você pede algo ao Claude: perfil, cursos, tarefas, entregas, notas, avisos, módulos, páginas, arquivos, fóruns e calendário. O conector não acessa nenhum outro sistema e não vê dados de outras pessoas além do que a sua conta já pode ver no Canvas.

Credenciais

  • O token que você cola na página de autorização é conferido no Canvas e depois viaja apenas cifrado (AES-256-GCM) dentro dos tokens de acesso entregues ao Claude. O servidor não tem banco de dados e não grava o token nem as respostas do Canvas.
  • Para que você não precise reconectar todo mês, o conector estende a validade do próprio token no Canvas, no máximo uma vez por dia, quando o Claude renova o acesso. Nenhum token novo é criado.

Com quem os dados são compartilhados

  • Canvas (Instructure / PUC Minas): recebe as chamadas feitas em seu nome, como no site.
  • Anthropic (Claude): recebe o resultado de cada ferramenta que você usa na conversa, conforme a política de privacidade da Anthropic.
  • Provedor de hospedagem do conector (hoje, Cloudflare Workers): processa as requisições e pode manter registros técnicos, como endereço IP e horário.

Os dados não são vendidos, não alimentam anúncios e não são usados para nenhum outro fim.

Este site

Este site não usa cookies, rastreadores, análise de audiência nem scripts.

Envios em seu nome

Entregar tarefa e responder fórum só existem com a opção de envios ligada, e o Claude pede sua confirmação antes de cada envio.

Segurança

Todo tráfego usa HTTPS. A autorização segue OAuth 2.1 com PKCE e só devolve o acesso para endereços permitidos, como claude.ai e claude.com. O endereço do Canvas é fixo no servidor.

Como apagar seus dados

Remova o conector (ou o plugin) no Claude e apague o token em Canvas → Conta → Configurações. Sem o token, o acesso guardado pelo Claude deixa de funcionar.
