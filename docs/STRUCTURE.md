# Structure

One row per versioned directory. `npm run docs:check` fails if a versioned directory does not appear here
(the name goes in backticks with a trailing slash, e.g. `` `src/core/` ``).

```text
.
├── .claude/          # Claude Code configuration: permissions, hooks, rules and skills
├── .githooks/        # Versioned git hooks (enabled by `npm install`)
├── .claude-plugin/   # marketplace.json: this repo as a Claude plugin marketplace
├── .github/          # PR/issue templates, Dependabot, CODEOWNERS (no Actions, ADR 0006)
├── connectors/       # One remote MCP connector per folder, each becomes a marketplace plugin
│   ├── canvas-puc/   # PUC Minas Canvas LMS (plugin + src/ + Worker + generated server/remote.js)
│   ├── gmail/        # Multi-account Gmail, reading and management (plugin + src/ + Worker), ADR 0014, 0019
│   └── whatsapp/     # Self-hosted personal WhatsApp: Worker (src/) + Go bridge in the container (bridge/), ADR 0015
├── docs/             # Documentation — the source of truth (and the public GitHub Pages site)
├── scripts/          # Helper shell scripts (GitHub, secrets, pr:check)
├── src/              # Code shared between connectors (pure core, mcp, remote)
└── tools/            # Internal repository tools (bundle, docs, hooks)
```

## Where to put something new

| I want to add...                             | It goes in...                                                                          | And I document it in...                             |
| -------------------------------------------- | -------------------------------------------------------------------------------------- | --------------------------------------------------- |
| New connector                                | `connectors/<name>/` (`.claude-plugin/plugin.json`, http `.mcp.json`, `src/worker.ts`) | STRUCTURE.md, FUNCTIONS.md, PROCESSES.md, ROADMAP   |
| Remote server for a connector (HTTP + OAuth) | `connectors/<name>/src/remote.ts` + `src/remote/`                                      | ARCHITECTURE.md, PROCESSES.md (P08–P09), README     |
| Pure logic used by more than one connector   | `src/core/`                                                                            | FUNCTIONS.md, PROCESSES.md if it is a new flow      |
| Effect (IO, network, database, terminal)     | `src/<layer>/` as in ARCHITECTURE.md                                                   | FUNCTIONS.md (Effects field)                        |
| UI component                                 | the `uiDir` folder of `docs.config.json`                                               | UI.md                                               |
| Shared constant or data                      | next to the module that uses it; exported                                              | FUNCTIONS.md, "Data and constants" table            |
| Internal repository tool                     | `tools/<name>/`                                                                        | STRUCTURE.md, FUNCTIONS.md                          |
| Shell script                                 | `scripts/`                                                                             | STRUCTURE.md, WORKFLOW.md if it is part of the flow |
| Architecture decision                        | `docs/adr/NNNN-title.md`                                                               | `docs/adr/README.md`                                |
| Repeated step of working with Claude         | `.claude/skills/<name>/SKILL.md`                                                       | CLAUDE.md (skill list)                              |
| Rule that only applies to some paths         | `.claude/rules/<name>.md` with `paths`                                                 | CLAUDE.md                                           |
| New directory of any kind                    | —                                                                                      | STRUCTURE.md (this table and the tree)              |
